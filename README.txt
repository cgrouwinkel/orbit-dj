ORBIT DJ v2.1.0 (Arcade)
Free, open-source DJ learning game. Original synthesized music and samples only.

Deploy: upload this whole folder's contents (or the ZIP) to Netlify. index.html must be at the root,
with css/, js/, icons/ and samples/ beside it. No build step, no server code.

Files
  index.html            app shell
  css/orbit.css         both themes (Grunge Arcade, Cyber Aero)
  js/util.js            helpers + storage
  js/sounds-manifest.js list of every sound file (generated by tools/make_sounds.py)
  js/engine.js          Web Audio engine: unlock, buses, reverb, glue, limiter, clock, sample players
  js/assets.js          sound loader: prefetch, decode, rebuild after iOS audio resets
  js/music.js           6 original song arrangements, charts from their drums, scheduler
  js/game.js            venues, scoring, equipment lessons/challenges
  js/beatpad.js         MPC-style beat pad: sequencer, record, note repeat, bounce WAV
  js/ui.js              interface, highway renderer, overlays
  sw.js                 network-first service worker with versioned offline cache
  sounds/               76 original synthesized sounds: 3 drum kits, 11 instruments, fx
  samples/              48 original WAV chops from v1 (3 banks x 16)

Honest scope: this is a rhythm-game DJ trainer with a beat pad. The crossfader blends layers of one
song; it is not yet independent two-deck mixing. Audio latency varies by device and headphones;
use Setup > Tap test to calibrate.
